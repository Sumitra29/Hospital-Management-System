# 🏥 Hospital Management System

A web-based Hospital Management System developed using PHP and MySQL. 

## 🚀 Part 1 – Features Implemented

- **Login Authentication:** User login using PHP sessions.
- **Session Management:** Maintains authenticated user sessions.
- **Logout:** Securely terminates the user session.
- **Dashboard:** Complete dashboard interface.
- **Header:** Common header navigation.
- **Sidebar:** Dashboard sidebar navigation.
- **Footer:** Common footer section.

## 💻 Installation & Setup

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone this repository:

   ```bash
   git clone https://github.com/Sumitra29/Hospital-Management-System.git
   ```

3. Place the project folder inside the XAMPP `htdocs` directory.
4. Start Apache and MySQL from XAMPP Control Panel.
5. Configure your database connection in the project configuration file.
6. Import the database SQL file using phpMyAdmin, if provided.
7. Open the project in your browser:

   ```text
   http://localhost/hospital_management_system/
   ```
